# i.conatus | 설치 가이드

> **이 문서는 아직 Claude Code가 없는 상태에서, 지금 쓰고 있는 아무 AI 채팅에게 주는 문서입니다.**
> VS Code 설치부터 Claude Code 확장 프로그램 로그인·연결까지만 다룹니다. 실제 업무 자동화 내용은 여기 없습니다.

## 이 문서를 읽는 AI에게

이 문서를 받은 즉시 설치하거나 실행하지 마세요.

1. 문서 전체의 목적과 진행 순서를 먼저 파악합니다.
2. 사용자가 Windows를 사용하는 비개발자라고 가정하고 전문 용어를 쉽게 설명합니다.
3. 사용자의 현재 상태를 먼저 질문합니다.
4. 한 번에 한 단계만 안내하고 완료 기준을 확인한 뒤 다음 단계로 이동합니다.
5. 명령어를 제시할 때 입력 위치·목적·예상되는 변화를 함께 설명합니다.
6. 삭제·덮어쓰기·개인정보 업로드·외부 전송·결제·계정·권한 변경은 사용자의 명시적인 승인을 기다립니다.
7. 비밀번호·API 키·인증번호를 채팅에 입력하도록 요청하지 않습니다.
8. 확인하지 못한 내용은 추측하지 않고 '확인 필요'라고 표시합니다.
9. 공식 문서와 이 가이드가 다르면 공식 문서를 우선하고 차이를 설명합니다.
10. 같은 오류가 세 번 반복되면 멈추고 원인을 다시 확인합니다.

## 처음 보고할 내용

사용자에게 다음 내용만 먼저 보고합니다.

1. 사용자가 거쳐야 할 전체 단계 (계정 확인 → VS Code 설치 → 확장 프로그램 설치 → 로그인 · 연결)
2. 현재 상태를 확인하기 위한 질문
3. 설치나 설정 변경이 필요한 항목
4. 사람의 승인이 필요한 항목
5. 지금 시작해야 할 첫 번째 단계

이 문서에는 시리즈 1·2·3 같은 실제 업무 자동화 내용이 없습니다. 로그인과 연결이 끝나면 이 문서의 역할은 끝나고, 아래 "로그인·연결이 끝난 뒤 반드시 할 일"로 넘어갑니다.

## 00 시작 안내

> **이 페이지는 사람과 AI가 함께 사용하는 시작 안내입니다.**
>
> 사람은 이 자료를 AI에게 전달하고 중요한 판단을 승인합니다. AI는 이 페이지의 행동 규칙을 시리즈 1·2·3 전체에서 지킵니다.
저자: **i.conatus**
### 이 자료의 목적
이 가이드는 Windows를 사용하는 비개발자가 Claude Code를 준비하고, 자신의 업무를 AI와 함께 자동화할 수 있도록 돕습니다.
모든 사용법을 외우는 것이 목적은 아닙니다. 중요한 것은 다음 세 가지입니다.
1. 현재 상황과 하려는 일을 AI에게 정확히 설명하기
2. AI가 제시한 작업의 완료 기준을 확인하기
3. 돈·개인정보·삭제처럼 중요한 판단은 사람이 맡기
### 이 자료를 읽는 AI에게
당신의 역할은 사용자가 Windows 환경에서 업무 자동화를 진행하도록 돕는 것입니다.
사용자는 비개발자일 수 있습니다. 전문 용어를 처음 사용할 때는 쉬운 말로 풀어 설명하세요. 사용자가 모든 기술을 외우게 하기보다, 현재 상황을 설명하고 중요한 질문을 할 수 있도록 도우세요.
#### 공통 진행 규칙
1. 먼저 이 자료의 전체 목적과 진행 순서를 파악합니다.
2. 아직 설치하거나 설정을 변경하지 않습니다.
3. 사용자의 현재 상태부터 질문합니다.
4. 이미 완료됐다는 답을 받더라도 가능한 범위에서 확인 근거를 요청합니다.
5. 한 번에 한 단계만 안내합니다.
6. 사용자가 완료했다고 답하면 완료 기준을 확인한 뒤 다음 단계로 넘어갑니다.
7. 명령어를 제시할 때 입력 위치와 목적을 함께 설명합니다.
8. AI가 할 일과 사용자가 직접 할 일을 구분합니다.
9. 링크된 참고자료는 현재 단계에서 필요할 때만 확인합니다.
10. 자료의 내용이 현재 공식 문서와 다르면 공식 문서를 우선하고 변경점을 사용자에게 설명합니다.
11. 링크를 열 수 없으면 내용을 추측하지 말고 사용자에게 해당 페이지 본문을 요청합니다.
12. 같은 오류가 반복되면 새로운 해결책을 계속 덧대지 말고 원인을 다시 확인합니다.
#### 입력 위치 표시 규칙
안내할 때 각 행동 앞에 다음 중 하나를 표시합니다.
- **\[VS Code에서 할 일\]**
- **\[터미널에 입력\]**
- **\[Claude 채팅에 입력\]**
- **\[Claude Code에 입력\]**
- **\[사용자가 직접 확인\]**
#### 반드시 승인을 기다릴 작업
다음 작업은 이유와 예상되는 변화를 설명하고 사용자의 승인을 받은 뒤 진행합니다.
- 프로그램 설치 또는 제거
- 관리자 권한 사용
- 파일 삭제 또는 기존 파일 덮어쓰기
- 계정·로그인·요금제 변경
- 결제 또는 돈이 움직이는 작업
- 외부 이메일·메시지·게시물 전송
- 개인정보가 포함된 자료의 업로드
- 보안 설정 또는 중요 시스템 설정 변경
- 되돌리기 어려운 작업
#### 즉시 중단할 조건
다음 상황에서는 추측해서 진행하지 않습니다.
- 비밀번호, API 키 또는 인증번호를 채팅에 입력해야 하는 상황
- 보안 프로그램을 끄라는 안내가 필요한 상황
- 공식 문서와 현재 화면이 크게 다른 상황
- 같은 오류가 세 번 반복된 상황
- 기존 업무자료가 삭제되거나 손상될 가능성이 있는 상황
- 현재 작업이 사용자가 요청한 범위를 벗어나는 상황
### AI에게 전달하는 시작 프롬프트
```plain text
첨부한 PDF 또는 아래 노션 페이지는
Windows에서 Claude Code를 준비하고
업무 자동화를 시작하기 위한 가이드야.

[PDF를 첨부하거나 노션 링크 입력]

자료 전체의 목적과 진행 순서를 먼저 파악해줘.
아직 설치하거나 설정을 변경하지 마.

먼저 다음 내용만 알려줘.

1. 내가 거쳐야 할 전체 단계
2. 현재 상태를 확인하기 위해 내게 물어볼 질문
3. 설치나 설정 변경이 필요한 항목
4. 사람의 승인이 필요한 항목
5. 지금 시작해야 할 첫 번째 단계

나는 비개발자야.
전문 용어는 쉬운 말로 설명하고,
한 번에 한 단계씩 진행해줘.
```
### AI의 단계별 보고 형식
각 단계가 끝날 때 다음 형식으로 보고합니다.
```plain text
현재 단계:
상태: 완료 / 미완료 / 확인 필요

확인한 내용:
확인 근거:
발견된 문제:

다음 단계:
AI가 할 일:
사용자가 할 일:
예상되는 변경:

승인 필요 여부:
승인이 필요한 이유:
```
### 링크를 열 수 없을 때
AI가 이 노션 페이지나 참고자료 링크를 열 수 없다면 다음 순서로 대응합니다.
1. 링크를 열 수 없다고 사용자에게 알립니다.
2. 필요한 페이지의 이름을 정확히 말합니다.
3. 사용자가 그 페이지의 본문을 복사해 전달할 때까지 기다립니다.
4. 기억이나 추측으로 설치 명령을 만들지 않습니다.

## Windows 환경 확인

> 이 페이지는 독자가 직접 공부하기 위한 설명서이면서, AI가 설치 환경을 점검할 때 참고하는 자료입니다.
### 목적
Windows PC가 Claude Code와 VS Code를 설치할 수 있는 기본 상태인지 확인합니다.  
이 단계에서는 설정을 바꾸거나 프로그램을 설치하지 않습니다.
### AI가 먼저 지켜야 할 원칙
- 한 번에 한 단계만 안내합니다.
- 독자에게 아래 항목만 확인하도록 요청합니다.
	- Windows 에디션과 버전
	- 시스템 종류: x64 또는 ARM64
	- 회사·학교에서 관리하는 PC인지
	- 프로그램을 설치할 권한이 있는지
- 장치 이름, 제품 ID, 장치 ID, 시리얼 번호처럼 불필요한 정보는 요청하지 않습니다.
- 독자에게 **설정 화면 전체 캡처를 채팅에 올리라고 요청하지 않습니다.**
- 회사·학교에서 관리하는 PC이거나 설치 권한이 불분명하면 임의로 제한을 우회하지 말고 담당자 확인을 안내합니다.
### 확인 방법 1 — Windows 설정 사용
1. 시작 버튼을 누릅니다.
2. **설정**을 엽니다.
3. **시스템 → 정보(About)**로 이동합니다.
4. 다음 두 가지만 확인합니다.
	- Windows 사양: 에디션과 버전
	- 장치 사양: 시스템 종류
독자는 다음 형식처럼 필요한 내용만 글자로 전달합니다.
```plain text
Windows 에디션/버전: Windows 11, 24H2
시스템 종류: 64비트 운영 체제, x64 기반 프로세서
관리 PC 여부: 아니요
프로그램 설치 권한: 있음
```
> 실제 값이 다르면 화면에 표시된 값을 그대로 적습니다. 제품 ID나 장치 ID는 적지 않습니다.
### 확인 방법 2 — 설정 화면을 찾기 어려울 때
1. 시작 메뉴의 검색창에 `winver`를 입력합니다.
2. **winver**를 실행합니다.
3. 표시된 Windows 에디션과 버전만 AI에게 알려줍니다.
4. 시스템 종류(x64/ARM64)는 방법 1의 **시스템 → 정보**에서 별도로 확인합니다.
### AI의 판단 기준
- **Windows 11 + x64/ARM64 + 설치 권한 있음**: 다음 단계로 진행합니다.
- **Windows 10**: 지원 종료 가능성을 알리고, 현재 환경에서 설치 가능한지 공식 문서를 다시 확인한 뒤 진행합니다. 운영체제 업그레이드를 AI가 임의로 지시하지 않습니다.
- **회사·학교 관리 PC 또는 설치 권한 없음**: 관리자에게 VS Code, Git for Windows, Claude Code 설치 허용 여부를 확인하도록 안내하고 멈춥니다.
- **에디션·버전·시스템 종류를 확인하지 못함**: 추측하지 말고 독자가 보고 있는 메뉴 이름을 물어 한 단계씩 안내합니다.
### 완료 체크리스트
- [ ] Windows 에디션과 버전을 확인했다.
- [ ] 시스템 종류가 x64인지 ARM64인지 확인했다.
- [ ] 회사·학교 관리 PC인지 확인했다.
- [ ] 프로그램 설치 권한이 있는지 확인했다.
- [ ] 불필요한 장치 식별 정보를 공유하지 않았다.
- [ ] AI가 다음 단계 진행 가능 여부를 한 문장으로 설명했다.
### AI에게 붙여넣을 문장
```plain text
이 페이지의 지침에 따라 내 Windows 환경을 확인해줘.
한 번에 한 단계만 안내하고, 장치 이름·제품 ID·장치 ID처럼 설치에 필요 없는 정보는 요청하지 마.
확인이 끝나면 결과를 '확인한 항목 / 판단 / 다음 단계'로 정리해줘.
```
### 공식 참고자료
- Microsoft: [Windows 장치 정보 확인](https://support.microsoft.com/en-us/windows/32-bit-and-64-bit-windows-frequently-asked-questions-c6ca9541-8dce-4d48-0415-94a3faa2e13d)
> 운영체제와 설치 조건은 바뀔 수 있습니다. AI는 실제 설치를 시작하기 전에 연결된 공식 문서의 최신 내용을 다시 확인해야 합니다.

## VS Code 설치

> 이 페이지는 Windows에 Visual Studio Code(VS Code)를 처음 설치할 때 AI가 참고하는 실행 안내서입니다.
### 목적
독자가 공식 배포처에서 VS Code를 설치하고, 업무 자동화를 진행할 전용 폴더를 VS Code로 열 수 있게 합니다.
### 먼저 알아둘 것
- **VS Code**는 파일과 폴더를 보면서 AI와 함께 작업할 작업 공간입니다.
- **Visual Studio**와 **Visual Studio Code**는 다른 프로그램입니다. 이 가이드에서는 Visual Studio Code를 사용합니다.
- 이 단계에서는 Claude Code 확장 프로그램을 아직 설치하지 않습니다.
- 설치 파일은 반드시 공식 주소 `code.visualstudio.com`에서 받습니다.
### AI가 먼저 확인할 것
1. Windows 환경 확인 페이지의 점검이 완료됐는지 묻습니다.
2. 시스템 종류가 x64인지 ARM64인지 확인합니다.
3. 회사·학교 관리 PC이거나 설치 권한이 없다면 설치를 진행하지 않습니다.
4. 독자가 현재 보고 있는 화면을 확인한 뒤 한 번에 한 단계만 안내합니다.
### 설치 순서
#### 1. 공식 다운로드 페이지 열기
- 다운로드: [Visual Studio Code 공식 다운로드](https://code.visualstudio.com/download)
> 이 다운로드 링크로 곧바로 이동합니다. 검색 결과나 설치 안내 문서 페이지(`/docs/setup/windows`)를 먼저 거치지 않습니다 — 그 페이지에는 큰 다운로드 버튼이 없어 헷갈릴 수 있습니다.
1. 위 다운로드 링크를 엽니다.
2. 주소창의 도메인이 `code.visualstudio.com`인지 확인합니다.
3. 페이지 중앙의 큰 **Windows** 버튼을 클릭합니다. Windows 10·11 x64 PC라면 이 버튼 하나로 충분합니다. ARM64 PC라면 버튼 아래의 **User Installer Arm64** 링크를 따로 선택합니다.
4. 브라우저의 다운로드 목록에서 `VSCodeUserSetup`으로 시작하는 `.exe` 파일을 확인합니다.
광고나 비공식 다운로드 사이트에서는 설치 파일을 받지 않습니다.
#### 2. 설치 파일 선택하기
일반적인 개인용 Windows PC라면 **User Setup**을 우선 선택합니다.
- x64 PC: Windows x64용 User Setup
- ARM64 PC: Windows Arm64용 User Setup
- 회사·학교 PC: 임의로 선택하지 말고 담당자의 설치 기준을 확인
User Setup은 일반적으로 관리자 권한 없이 설치할 수 있어 초보자에게 적합합니다. 다만 조직의 보안 정책이 있으면 그 정책이 우선입니다.
#### 3. 설치하기
1. 브라우저의 다운로드 목록 또는 Windows의 **다운로드** 폴더에서 내려받은 `.exe` 설치 파일을 실행합니다.
2. Windows가 실행 여부를 묻는다면 게시자가 Microsoft인지 확인한 뒤 진행합니다.
3. 사용권 계약을 확인하고 설치를 진행합니다.
4. 설치 위치와 시작 메뉴 폴더를 잘 모르겠다면 기본값을 유지합니다.
5. **PATH에 추가(Add to PATH)** 항목이 보이면 선택 상태를 유지합니다.
6. **설치(Install)**를 선택하고 완료될 때까지 기다립니다.
7. 설치가 끝나면 **Visual Studio Code 실행**을 선택하거나 시작 메뉴에서 VS Code를 실행합니다.
> 설치 중 관리자 암호나 조직의 승인 화면이 나타나면 우회하지 말고 멈춥니다.
#### 4. 프로그램을 완전히 다시 열기
설치가 끝난 뒤 기존에 열려 있던 명령 프롬프트, PowerShell, Windows Terminal은 새 설정을 바로 인식하지 못할 수 있습니다.
1. 열려 있던 VS Code와 터미널 창을 모두 닫습니다.
2. 시작 메뉴에서 **Visual Studio Code**를 다시 실행합니다.
3. 문제가 계속되면 AI가 재부팅을 지시하기 전에 현재 오류 문구부터 확인합니다.
#### 5. 업무 자동화 전용 폴더 만들기
문서나 바탕 화면처럼 찾기 쉬운 위치에 빈 폴더 하나를 만듭니다.
권장 예시:
```plain text
업무자동화
```
처음에는 한글 폴더명도 사용할 수 있습니다. 다만 어떤 도구에서 경로 문제가 생기면 AI가 오류를 확인한 뒤 영문 폴더명(예: `work-automation`)을 제안할 수 있습니다.
#### 6. VS Code에서 폴더 열기
1. VS Code 상단 메뉴에서 **File → Open Folder**를 선택합니다.
2. 방금 만든 업무 자동화 폴더를 선택합니다.
3. 신뢰 여부를 묻는 창이 나오면 **직접 만든 빈 폴더가 맞는지 확인한 뒤** 신뢰합니다.
4. 왼쪽 탐색기에 폴더 이름이 보이는지 확인합니다.
### 완료 체크리스트
- [ ] 공식 도메인에서 VS Code 설치 파일을 받았다.
- [ ] 내 시스템 종류에 맞는 설치 파일을 선택했다.
- [ ] VS Code 설치를 완료했다.
- [ ] 기존 프로그램을 닫고 VS Code를 다시 실행했다.
- [ ] 업무 자동화 전용 폴더를 만들었다.
- [ ] VS Code에서 그 폴더를 열었다.
- [ ] 왼쪽 탐색기에 폴더 이름이 보인다.
### AI가 확인할 완료 보고
AI는 다음 형식으로만 정리합니다.
```plain text

확인: 왼쪽 탐색기에 [폴더명] 표시
보류: 없음 또는 해결하지 못한 항목

```
### 막혔을 때

- x64와 ARM64를 모르겠음: Windows 환경 확인 페이지로 돌아갑니다.
- 관리자 승인이 필요함: 설치를 중단하고 PC 관리자에게 확인합니다.

## Claude Code 설치

> 초보자용 기본 경로는 VS Code 안에서 Anthropic의 공식 Claude Code 확장 프로그램을 설치하는 것입니다.
### 목적
VS Code에 공식 Claude Code 확장 프로그램을 설치하고 로그인한 뒤, 업무 자동화 전용 폴더에서 Claude Code 대화창을 열 수 있게 합니다.
### 이 가이드가 선택한 설치 방식
Claude Code를 사용하는 방법은 여러 가지지만 이 가이드는 **VS Code 공식 확장 프로그램**을 기본 경로로 사용합니다.
- 장점: VS Code 안에서 설치·대화·파일 확인을 함께 할 수 있습니다.
- 공식 안내 기준으로 확장 프로그램에 Claude Code 명령줄 기능이 포함되므로, 초보자가 먼저 별도 설치 명령을 실행할 필요가 없습니다.
- 별도 명령줄 설치는 확장 프로그램 설치가 불가능하거나 고급 사용이 필요할 때만 대안으로 검토합니다.
> 설치 방식은 바뀔 수 있습니다. AI는 시작 전에 Anthropic 공식 문서에서 현재 안내를 다시 확인합니다.
### AI가 먼저 확인할 것
- VS Code 설치가 완료됐는지
- Git이 현재 업무에 실제로 필요한지(필요할 때만 Git for Windows 설치를 확인)
- VS Code에 업무 자동화 전용 폴더가 열려 있는지
- 회사·학교 관리 PC에서 확장 프로그램 설치가 허용되는지
### 1. 확장 프로그램 화면 열기
1. VS Code 왼쪽의 **Extensions(확장 프로그램)** 아이콘을 누릅니다.
2. 또는 키보드에서 `Ctrl+Shift+X`를 누릅니다.
3. 검색창에 `Claude Code`를 입력합니다.
> 🖼️ **이미지 자리 1 — 검색 결과에서 공식 확장 프로그램 선택**
> 검색 결과의 첫 번째 항목이라고 무조건 설치하지 않습니다. 이름이 **Claude Code for VS Code**이고 게시자가 **Anthropic**인 항목을 선택합니다. `Unofficial`, `YOLO` 또는 다른 게시자가 만든 비슷한 이름의 확장 프로그램은 이 가이드의 설치 대상이 아닙니다.
### 2. 공식 확장 프로그램인지 확인하기
설치 버튼을 누르기 전에 다음을 확인합니다.
- 이름: **Claude Code for VS Code**
- 게시자(Publisher): **Anthropic**
- 게시자 인증 표시
- 공식 도메인: `anthropic.com`
- 확장 프로그램 식별자: `anthropic.claude-code`
> 🖼️ **이미지 자리 2 — 상세 화면에서 공식 정보 확인**
> 이름, Anthropic 게시자, 인증 표시, `anthropic.com`, `anthropic.claude-code`를 확인한 뒤 Install을 선택합니다.
이름이 비슷해도 게시자가 Anthropic이 아니면 설치하지 않습니다. 검색 결과가 여러 개이거나 확신이 없으면 AI는 설치를 지시하지 말고 독자에게 **확장 프로그램 이름과 게시자만** 적어 달라고 요청합니다.
### 3. 설치하기
1. 공식 확장 프로그램의 **Install**을 누릅니다.
2. 설치가 완료될 때까지 기다립니다.
3. Claude Code 패널이 자동으로 열리지 않으면 VS Code를 완전히 닫고 다시 엽니다.
4. 그래도 보이지 않으면 명령 팔레트(`Ctrl+Shift+P`)에서 `Claude Code`를 검색합니다.
> 확장 프로그램이 요구하는 VS Code 최소 버전을 충족하지 못하면, 비공식 파일을 찾지 말고 VS Code 공식 업데이트를 먼저 검토합니다.
> 📹 **참고 영상**: [VS Code에서 Claude Code 시작하기 — macOS 참고 영상](https://diamonds0821.github.io/i-conatus-ai-guide/docs/assets/videos/vscode-claude-code-getting-started-macos.mp4)
> 이 가이드의 기본 환경은 Windows입니다. 영상은 macOS에서 촬영되어 단축키·메뉴 모양이 다를 수 있습니다. 설치와 로그인 흐름을 이해하는 보조자료로만 사용하고, 실제 조작은 이 문서의 Windows 절차를 따릅니다.
### 4. 로그인하기
1. Claude Code 패널의 로그인 안내를 누릅니다.
2. 브라우저가 열리면 Anthropic 공식 로그인 화면인지 주소를 확인합니다.
3. 독자가 본인의 계정으로 직접 로그인합니다.
4. 비밀번호, 인증 코드, API 키는 AI 채팅에 붙여넣지 않습니다.
5. 로그인 후 VS Code로 돌아옵니다.
구독 또는 조직 계정 조건이 맞지 않는다는 메시지가 나오면 결제를 임의로 진행하지 않습니다. 현재 계정에서 사용할 수 있는 방법을 공식 안내로 확인한 뒤 독자에게 선택을 요청합니다.
### 5. 첫 화면 확인하기
- 업무 자동화 전용 폴더가 열려 있는지 확인합니다.
- Claude Code 채팅 입력란이 보이는지 확인합니다.
- 아직 파일을 만들거나 수정하지 않습니다.
처음에는 아래 문장만 입력합니다.
```plain text
지금 열려 있는 작업 폴더의 이름과 보이는 파일 개수만 알려줘.
아직 파일을 만들거나 수정하거나 명령을 실행하지 마.
```
Claude Code가 폴더 이름과 파일 개수를 답하면 기본 연결이 확인된 것입니다.
### 입력 위치 구분
- **Claude Code에게 일을 요청하는 문장** → Claude Code 채팅 입력란
- 컴퓨터 명령어(예: `git --version`) → VS Code 터미널
- **웹 주소** → 브라우저 주소창
AI는 독자에게 무엇을 입력하라고 할 때마다 입력 위치를 먼저 표시합니다.
### 6. 권한 모드 Auto 설정하기
1. Claude Code 입력창 아래의 권한 모드 표시를 누릅니다.
2. **Auto**를 선택합니다.
3. **Edit automatically** 또는 **권한 우회(Bypass permissions)**가 선택되지 않았는지 확인합니다.
4. Auto가 보이지 않으면 Manual을 사용하고 계정·버전·조직 정책을 공식 문서에서 확인합니다.
Auto는 분류기가 대부분의 행동을 검토해 반복적인 승인창을 줄이는 모드입니다. 그러나 해당 행동을 기술적으로 모두 차단하거나 안전을 보장하는 설정은 아닙니다. 파일 삭제·원본 덮어쓰기·작업 폴더 밖 접근·개인정보 업로드·외부 전송·결제·로그인·권한 변경처럼 민감한 작업을 시작하기 전에는 **Manual 또는 Plan** 모드로 전환하고 사용자가 직접 확인합니다.
> 📹 **참고 영상**: [Claude Code 추가 설정 — macOS 참고 영상](https://diamonds0821.github.io/i-conatus-ai-guide/docs/assets/videos/claude-code-additional-settings-macos.mp4)
> 권한 모드, 알림, 그 밖의 기본 설정 화면을 보여주는 macOS 참고 영상입니다. 메뉴 위치는 Windows와 다를 수 있으니 실제 조작은 이 문서 기준으로 합니다.
### 완료 체크리스트

- [ ] 이름이 Claude Code인지 확인했다.

## VS Code에서 Claude Code 사용

> 설치가 끝난 뒤에는 “어디에 입력하는가”와 “AI가 실제로 무엇을 바꾸는가”를 구분하는 것이 가장 중요합니다.
### 목적
VS Code 안에서 Claude Code와 안전하게 대화하고, 파일 변경 전후를 확인하는 기본 사용법을 익힙니다.
### 화면의 네 영역
1. **탐색기(Explorer)**: 현재 작업 폴더와 파일을 보는 곳
2. **편집기(Editor)**: 선택한 파일 내용을 보는 곳
3. **Claude Code 채팅**: AI에게 목적·조건·확인 방법을 말하는 곳
4. **터미널(Terminal)**: 컴퓨터 명령어를 직접 실행하는 곳
Claude Code가 명령 실행을 제안할 수는 있지만, 독자가 명령어를 직접 입력해야 한다면 AI는 반드시 입력 위치를 ‘터미널’이라고 먼저 표시합니다.
### AI에게 일을 요청하는 기본 형식
질문을 어렵게 꾸밀 필요는 없습니다. 다음 네 가지만 말하면 됩니다.
```plain text
목적: 무엇을 하고 싶은지
현재 상황: 지금 가진 파일과 반복 업무
조건: 바꾸면 안 되는 것, 사용하는 프로그램, 시간·비용 제한
완료 확인: 어떤 결과가 나오면 끝인지
```
예시:
```plain text
목적: 매주 내려받는 주문 파일의 열 이름을 같은 형식으로 정리하고 싶어.
현재 상황: 아직 실제 파일은 넣지 않았고, 빈 작업 폴더만 열어뒀어.
조건: 원본 파일은 절대 덮어쓰지 말고 개인정보가 있으면 먼저 알려줘.
완료 확인: 예시 파일로 변환 전후를 비교할 수 있으면 돼.
먼저 계획만 설명하고, 파일을 만들거나 명령을 실행하지 마.
```
### 첫 작업은 세 단계로 나누기
#### 1. 읽기와 질문
Claude Code에게 현재 폴더를 읽고, 모르는 점을 질문하게 합니다.  
이때는 파일 생성·수정·삭제와 명령 실행을 금지합니다.
#### 2. 계획 확인
Claude Code가 아래 내용을 설명하게 합니다.
- 만들거나 바꿀 파일
- 실행할 명령
- 원본 데이터에 미치는 영향
- 사람이 확인해야 할 지점
- 실패하면 되돌리는 방법
독자가 이해하지 못한 용어가 있으면 실행 전에 쉬운 말로 다시 설명하게 합니다.
#### 3. 작은 실행과 검증
전체 업무를 한 번에 자동화하지 않습니다. 개인정보가 없는 예시 자료나 복사본으로 가장 작은 한 단계만 실행합니다.  
결과를 사람이 확인한 뒤 다음 단계로 넘어갑니다.
### 권한 모드 Auto로 시작하기
이 가이드의 기본 추천은 **Auto**입니다. Claude Code 입력창 아래의 권한 모드 표시를 누르고 **Auto**를 선택합니다.
Auto에서는 분류기가 대부분의 행동을 검토하므로, 안전한 작업 폴더 안에서 작은 자동화를 실제로 실행하며 효과를 빠르게 느낄 수 있습니다. 다만 작업 폴더의 파일을 묻지 않고 편집할 수 있으므로, 실행 전에는 대상·범위·완료 기준·중단 조건을 프롬프트에 분명히 적습니다.
- **Auto**: 분류기가 대부분의 행동을 검토합니다. 이 가이드의 기본 추천입니다.
- **Manual**: 파일 편집과 대부분의 명령 전에 승인을 묻습니다. Auto가 보이지 않을 때 임시로 사용합니다.
- **Plan**: 변경 전에 계획을 작성하고 승인을 기다립니다. 복잡한 작업을 설계할 때 선택할 수 있습니다.
- **Edit automatically**: 묻지 않고 편집하므로 이 초보자 가이드에서는 사용하지 않습니다.
- **권한 우회(Bypass permissions)**: 인터넷이 차단된 별도 시험환경용 기능이므로 사용하지 않습니다.
Auto를 선택해도 파일 삭제·원본 덮어쓰기·작업 폴더 밖 접근·개인정보 업로드·외부 전송·결제·로그인·권한 변경은 사람이 별도로 승인합니다. 이는 이 가이드의 작업 원칙이며, Auto가 해당 행동을 기술적으로 모두 차단하거나 안전을 보장한다는 뜻은 아닙니다. 민감한 작업을 시작하기 전에는 **Manual 또는 Plan** 모드로 전환하고 사용자가 직접 확인합니다.
### 승인 요청을 만났을 때
Auto에서도 위험하거나 판단이 필요한 행동은 승인 요청 또는 확인 질문이 나타날 수 있습니다. 승인 창은 오류가 아니라 **사람이 판단해야 하는 지점**입니다.
승인 전에 확인합니다.
- 무엇을 읽거나 바꾸는가?
- 작업 폴더 밖에 영향을 주는가?
- 파일을 삭제하거나 덮어쓰는가?
- 돈·결제·전송·로그인과 관련되는가?
- 되돌릴 방법이 있는가?
내용을 이해하지 못하면 승인하지 말고 이렇게 묻습니다.
```plain text
이 승인이 내 컴퓨터에서 무엇을 바꾸는지 비개발자도 이해할 수 있게 설명해줘.
대상 파일이나 폴더, 되돌리는 방법, 승인하지 않았을 때 생기는 일을 알려줘.
아직 실행하지 마.
```
### 변경 내용을 확인하는 습관
Claude Code가 파일을 바꾼 뒤에는 다음을 요청합니다.
```plain text
바꾼 파일 목록과 각 파일에서 달라진 내용을 요약해줘.
요청하지 않은 변경이 있는지 확인하고, 내가 직접 확인할 방법도 알려줘.
```
VS Code에서 변경 전후 비교 화면이 보이면 삭제된 내용과 추가된 내용을 확인합니다. 이해하지 못한 변경은 다음 작업으로 넘기지 않습니다.
### 기본 안전선
Claude Code가 아래 행동을 하려면 독자에게 별도 확인을 받아야 합니다.
- 파일 삭제 또는 원본 덮어쓰기
- 작업 폴더 밖의 파일 접근
- 이메일·메시지·게시물 전송
- 결제·송금·구매·예약 확정
- 외부 서비스 로그인 또는 권한 연결
- 많은 파일의 일괄 변경
- 개인정보·고객정보를 외부 서비스로 전송
돈이 움직이거나 외부로 발송되는 마지막 단계는 완전 자동화하지 않고 사람이 승인하도록 설계합니다.
### 완료 체크리스트
- [ ] 탐색기·편집기·Claude 채팅·터미널을 구분할 수 있다.
- [ ] 권한 모드를 Auto로 설정하고 Auto의 범위를 이해했다.
- [ ] Edit automatically와 권한 우회 모드를 사용하지 않았다.
- [ ] 목적·현재 상황·조건·완료 확인을 AI에게 전달했다.
- [ ] 첫 요청에서 계획만 받았다.
- [ ] 변경 파일과 실행 명령을 미리 확인했다.
- [ ] 작은 예시로 먼저 시험했다.
- [ ] 승인 요청의 대상과 영향을 이해한 뒤 결정했다.
- [ ] 실행 후 변경 파일 목록과 확인 방법을 받았다.
- [ ] 돈·전송·삭제 같은 행동은 사람이 최종 승인하도록 남겼다.
### AI에게 붙여넣을 시작 문장
```plain text
이 페이지를 작업 규칙으로 사용해줘.
권한 모드는 Auto로 사용하되, 삭제·원본 덮어쓰기·작업 폴더 밖 접근·개인정보 업로드·외부 전송·결제·로그인·권한 변경 전에는 반드시 멈추고 내 승인을 기다려줘.
나는 비개발자이므로 매 단계마다 입력하거나 클릭할 위치를 먼저 알려줘.
먼저 내 목적·현재 상황·조건·완료 기준을 질문하고, 답을 받은 뒤 계획만 작성해줘.
내가 '실행해줘'라고 명확히 말하기 전에는 파일을 만들거나 수정하거나 삭제하지 말고 명령도 실행하지 마.
실행 후에는 바꾼 파일, 확인 결과, 남은 위험을 정리해줘.
```
### 다음 단계로 넘길 작업 요약
Claude Code와 기본 대화가 끝나면 다음 형식으로 현재 상태를 작성하게 합니다.
```plain text
작업 목적:
열어 둔 폴더:
현재 파일:
설치·연결 상태:
확인한 안전 규칙:
아직 실행하지 않은 것:
다음에 할 가장 작은 작업:
사용자에게 확인받을 사항:
```
이 요약은 브라우저 Claude에서 설치를 안내하던 대화와 VS Code의 Claude Code 작업을 이어 주는 인계 자료로 사용합니다.

## 로그인·연결이 끝난 뒤 반드시 할 일

Claude Code 로그인과 권한 모드(Auto) 설정까지 확인됐으면, 이 설치 가이드의 역할은 끝입니다. 사용자에게 아래 문장을 그대로 알려주고, 이번엔 **VS Code 안의 Claude Code 채팅창**에 붙여넣으라고 안내하세요. 지금부터는 이 문서가 아니라 작업 가이드가 안내를 이어갑니다.

```plain text
아래 가이드를 전체적으로 읽어줘.

https://raw.githubusercontent.com/diamonds0821/i-conatus-ai-guide/main/docs/i-conatus-work-guide.md

아직 파일을 만들거나 설정을 바꾸지 마.
먼저 내 현재 상태와 하려는 업무를 질문해줘.

나는 비개발자야.
전문 용어는 쉽게 설명하고, 한 번에 한 단계씩 진행해줘.
중요한 변경은 반드시 내 승인을 받아줘.
```
